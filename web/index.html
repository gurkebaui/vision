Hand-gesture recognition, running locally in your browser

This page runs the same recognition logic as the Python desktop app — the geometry, the smooth scoring rules, the temporal stabiliser — on top of MediaPipe's web build. Video never leaves your machine; there is no server and no upload.

This is a demo of the recogniser. It shows what the desktop app detects. It cannot press keys or move your mouse — browsers deliberately forbid that. For real control, run the Python app: pipx install gesturekit && gesturekit run

      What the desktop app adds

      Real input control

      Sends keystrokes, moves the cursor, clicks and scrolls through pynput, ydotool, xdotool or PyAutoGUI — including Wayland.

      Motion gestures

      Swipes and circles judged on straightness, speed and path length, so a wobble or a slow reposition never fires an action.

      Profiles

      Presentation, desktop, media and accessibility mappings in editable YAML, switchable at runtime.

      Virtual mouse

      Point to move, pinch to click, pinch-hold to drag, two fingers to scroll, two hands to zoom.

      Runs entirely on-device via MediaPipe Tasks Vision. MIT licensed.
